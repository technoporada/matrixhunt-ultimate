// CONTROLLER SETUP

Controller Setup Guide

  1. Connect your controller via USB or Bluetooth
  2. On Windows: Controllers are usually auto-detected. Use x360ce if needed.
  3. On Linux: Use 'jstest /dev/input/js0' to verify detection
  4. On Android: Bluetooth pair then configure in emulator settings
  5. Map buttons in each emulator's input settings
  6. Test with pad_test.html in the MatrixHunt dashboard

Recommended Controllers

Xbox Series Controller (best compatibility)
PS5 DualSense (good with Steam Input)
8BitDo Pro 2 (best for retro gaming)
